# Fixtures de desarrollo

| Archivo | Uso |
|---------|-----|
| `cra-priorities-sample.geojson` | Subset simplificado (~75 polígonos) para el mapa Leaflet. **No** es la capa completa (~14.7k) ni un inventario oficial publicado. |
| `invemar-zonificacion-atlantico.geojson` | 196 polígonos INVEMAR (geometría simplificada) con especie dominante / zonif. de manejo. Citar INVEMAR SIGMA. |
| `demo-reports.json` | Reportes de ejemplo para el dashboard en desarrollo. |

No presentar estos datos al jurado como cobertura completa C.R.A. sin aclarar que son fixtures.
