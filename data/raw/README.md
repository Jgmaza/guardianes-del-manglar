# data/raw — fuentes geográficas originales

Los archivos KMZ/KML de la C.R.A. se conservan aquí **sin modificar**.

| Archivo | Rol |
|---------|-----|
| `prioridades-conservacion.kmz` | Copia de trabajo del KMZ entregado |
| `prioridades-conservacion.kmz.sha256` | Checksum |
| `kmz_extract/` | Extracción local de `doc.kml` (no versionar si es muy pesado) |
| `invemar-zonificacion-atlantico/` | Descarga INVEMAR SIGMA Zonificación Atlántico (+ `SOURCE.txt`, sha256) |

No inventar atributos. No sobrescribir el KMZ original.
