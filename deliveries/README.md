# Deliveries

Entregas de diseño / assets por persona (mismo espíritu que en el juego).

```
deliveries/
  diogenes/   # visuales, exports .pen / capturas Figma, PDFs
  luis/       # si aplica material de soporte del bot
```

En cada carpeta deja un `README.md` con:

- Link al archivo Figma / Pencil (`.pen`) / otro
- Qué pantallas cubre
- Issue relacionado (`#n`)
